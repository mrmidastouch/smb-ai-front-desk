# SMB AI Front Desk

System design: AI phone answering and front desk deployment for local businesses, built and deployed by Midas Marketing.

## What the system does

- Answers calls around the clock.
- Books appointments.
- Captures and qualifies leads.
- Routes urgent calls to a human.
- Keeps the CRM updated.

## Deployment approach

- Map the business's real call flows first.
- Train on its services and hours.
- Test against real scenarios.
- Hand over with a simple owner dashboard.

## Status

This is a live, deployed client system. The client is unnamed. The system is multilingual by design.

This repo is system design documentation only. It contains no client names, no pricing, no vendor internals, no production code, and no prompts.
